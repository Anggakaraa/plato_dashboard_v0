## Getting Started

### Installation process

NodeJS Required 19.6.0

The command below ensure that you are running the correct NodeJS version:

(You must installed the nvm)

```bash
  nvm use
```

### Running

The commands bellows are starting the project according to the environment into env/*.env:

```bash
yarn start:local
yarn start:prod
yarn start:dev
```

### Build

The command bellow will generate the files into dist folder:

```bash
yarn build
```
